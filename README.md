# Jetpack Compose – Practical 5

## 📱 Project Overview

This project is developed as part of the Mobile Application Development (MAD) practical coursework. It demonstrates Android user interface development using **Jetpack Compose**, Android's modern declarative UI toolkit.

The project focuses on creating reusable UI components, managing input values, arranging interface elements, and handling user interactions using Kotlin.

## 🎯 Objectives

- Understand the fundamentals of Jetpack Compose.
- Build Android user interfaces using Kotlin.
- Create reusable composable functions.
- Manage UI state and user input.
- Implement layouts and Material Design components.
- Understand modifiers, padding, alignment, and arrangement.
- Improve code readability and component reusability.

## 🛠️ Technologies Used

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **UI Components:** Material 3
- **IDE:** Android Studio
- **Build System:** Gradle
- **Platform:** Android

## ✨ Concepts Covered

- `@Composable` functions
- `Column`, `Row`, and layout arrangements
- `Modifier` for styling and positioning
- `Text` and `OutlinedTextField`
- State management using Compose runtime
- Event handling through callback functions
- Reusable form components
- Material Design UI elements

## 🧩 Benefits of Jetpack Compose

- **Declarative UI:** Describe the interface based on application state.
- **Reusable components:** Build composable functions that can be reused.
- **Less boilerplate:** Reduce the need for traditional XML layouts.
- **State-driven updates:** Automatically update the UI when observed state changes.
- **Material Design support:** Use modern Android UI components and theming.
